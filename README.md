# Laundry Day Website

Static HTML/CSS/JS marketing website for **Laundry Day** — Melbourne's friendliest laundromat chain. Three locations across Melbourne's inner north and western suburbs. No frameworks, no build tools — just hand-crafted HTML.

**Live:** [laundryday.au](https://laundryday.au)

## What is Laundry Day?

A new laundromat chain opening three Melbourne locations with a distinctive brand: free detergent, zero card fees, giant 27KG washers, and a friendly dolphin mascot named Lila. The website is a StoryBrand-based single-page marketing site designed to convert local search traffic into footfall, supported by a 24-post SEO blog.

## Blog Publishing System

The blog uses a date-gating system — posts are written in advance and scheduled for future publication.

### How it works

1. Blog posts are static HTML files in `blog/` (e.g., `blog/how-to-wash-a-doona.html`)
2. `blog/posts.json` contains metadata for all posts with `date` fields (ISO format: `YYYY-MM-DD`)
3. `scripts/publish.py` reads `posts.json`, filters to posts where `date <= today` (AEST timezone), and regenerates:
   - `blog/index.html` — listing page showing only published posts
   - `sitemap.xml` — updated with published blog URLs
4. A GitHub Actions workflow (`scheduled-publish.yml`) runs daily at 7:00 AM AEST (cron: `0 20 * * *`), runs the Python script, and commits the updated files

### Adding a new blog post

1. Create `blog/<slug>.html` with the full post content
2. Add entry to `blog/posts.json` with slug, title, date, excerpt, and alt text
3. Add OG image at `assets/images/blog/<slug>.png` (600x315 recommended)
4. The post will go live automatically on its scheduled date when the GitHub Action runs

### Manual publish

```bash
python3 scripts/publish.py
```

This regenerates `blog/index.html` and `sitemap.xml` based on the current AEST date.
